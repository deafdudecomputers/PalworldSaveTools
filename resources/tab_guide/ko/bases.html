기능 개요

세이브에 있는 모든 거점을 검색할 수 있는 테이블입니다. 열에는 거점 ID, 길드 ID, 길드 이름, 길드 레벨이 표시됩니다. 마우스 우클릭 컨텍스트 메뉴를 통해 삭제, 범위 조정, 가져오기/내보내기, 복제, 길드 작업 등 전체 거점 관리 기능을 제공합니다.

기본 조작 (좌클릭 및 버튼)

  • 검색창에 입력하여 모든 열을 기준으로 거점을 필터링합니다.
  • 거점 행을 클릭하여 선택합니다.

고급 단축키 (더블 클릭 상호작용)

  • 거점 행을 더블 클릭하면 item_double_clicked 시그널이 발생합니다.
  • 기본 핸들러가 연결되어 있지 않아 현재 더블 클릭 시 눈에 보이는 효과는 없습니다.

숨겨진 메뉴 (우클릭 컨텍스트)

  • 거점 행을 우클릭하면 다음 항목을 이용할 수 있습니다: 제외 추가/제거, 거점 삭제(거점 ID 및 길드 ID 필요), 길드 이름 변경, 길드 레벨 설정, 거점 내보내기, 범위 조정, 거점 가져오기, 거점 복제.
  • 일부 작업은 거점 자체가 아닌 거점과 연관된 길드에 적용된다는 점에 유의하세요.

고급 사용자 팁

거점 삭제에는 거점 ID(열 인덱스 0)와 길드 ID(열 인덱스 1)가 모두 필요하며, 컨텍스트 메뉴는 두 항목을 함께 전달합니다. 비활성 거점 삭제 및 비거점 맵 오브젝트 삭제와 같은 대량 거점 정리는 메뉴 → 기능 경로를 사용하세요.
