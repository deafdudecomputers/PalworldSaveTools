기능 개요

모든 길드의 모든 거점에 대한 아이템 인벤토리와 거점 작업 팰을 탐색하고 관리합니다. 다음 두 하위 탭 간을 전환합니다: 인벤토리 (컨테이너 내 아이템 보기/편집) 및 거점 팰 (선택한 거점에 배치된 작업 팰 보기/관리).

기본 조작 (좌클릭 및 버튼)

  • 길드 버튼을 클릭해 검색 가능한 팝업을 열고 길드를 선택한 후, 거점 버튼을 클릭해 거점을 선택합니다.
  • 컨테이너 목록(왼쪽 패널)에서 컨테이너를 클릭하면 그리드에서 해당 아이템을 볼 수 있습니다.
  • 보기를 전환하려면 인벤토리 또는 거점 팰 탭 버튼을 클릭합니다.
  • 길드 간 아이템 작업(모든 길드에서 아이템 찾기/제거)을 열려면 아이템 버튼을 사용합니다.
  • 길드 간 구조물 삭제에는 구조 버튼을 사용합니다.
  • 거점 찾기 버튼은 아이템 필터와 일치하는 컨테이너가 있는 모든 거점을 검색합니다.
  • 거점에 배치된 작업 팰이 30마리를 초과하는 경우 거점 팰 그리드에서 마우스 스크롤 휠을 사용하여 페이지를 이동할 수 있습니다.

고급 단축키 (더블 클릭 상호작용)

  • 인벤토리 그리드의 아이템을 더블 클릭하면 해당 슬롯에서 아이템이 즉시 제거됩니다(확인 창 없음).
  • 빈 슬롯을 더블 클릭하면 해당 슬롯의 아이템 추가 대화상자가 열립니다.
  • 거점 팰 탭에서 팰 슬롯을 더블 클릭할 때: 팰이 있는 슬롯은 즉시 삭제되며(확인 창 없음), 빈 슬롯인 경우 새 팰 추가 대화상자가 열립니다.
  • 아이템 대화상자의 검색 목록에서 팰을 더블 클릭하면 해당 아이템을 보유한 컨테이너를 찾을 수 있습니다.

숨겨진 메뉴 (우클릭 컨텍스트)

  • 목록의 컨테이너를 우클릭하면 다음 메뉴를 사용할 수 있습니다: 아이템 추가(디버그), 컨테이너 초기화, 컨테이너 슬롯 수정, 컨테이너 삭제.
  • 그리드의 아이템을 우클릭하면 다음 메뉴를 사용할 수 있습니다: 수량 편집, 아이템 제거, 컨테이너 초기화.
  • 빈 그리드 슬롯을 우클릭하면 다음 메뉴를 사용할 수 있습니다: 아이템 추가, 컨테이너 초기화.
  • 데이터가 있는 팰 슬롯을 우클릭하면 다음 메뉴를 사용할 수 있습니다: 보스/럭키/각성/DNA 토글, 레벨 잠금(4단계), 모든 능력치 최대화, 모든 기술 습득, 습득한 스킬, 팰 일괄 동기화, 삭제.
  • 빈 팰 슬롯을 우클릭하면 다음 메뉴를 사용할 수 있습니다: 새 팰 추가.

고급 사용자 팁

거점 팰 탭에서 팰 슬롯 위에 마우스 커서를 올리면 정보 패널에서 해당 능력치를 미리 볼 수 있습니다. 하단의 페이지 이동 바는 현재 작업 팰 페이지를 표시합니다 — 이전/다음 버튼이나 스크롤 휠을 사용해 이동하세요.
