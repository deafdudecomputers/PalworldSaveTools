기능 개요

3개의 하위 탭으로 플레이어 인벤토리를 전체 관리할 수 있습니다: 인벤토리(메인 가방의 모든 아이템/장비), 주요 아이템(퀘스트 아이템, 조각상, 기술), 스탯(플레이어 속성: 레벨, HP, 스태미나, 공격, 방어, 작업 속도, 무게). 오른쪽 장비 패널에는 무기, 장신구, 음식, 방어구, 방패, 글라이더, 모듈 슬롯이 표시됩니다.

기본 조작 (왼쪽 클릭 및 버튼)

  • 플레이어 선택...을 클릭하여 검색 가능한 팝업에서 플레이어를 선택합니다 (입력하여 필터링, Enter로 선택).
  • 하위 탭을 클릭하여 뷰를 전환합니다.
  • 스탯 하위 탭에서 각 스탯 옆의 +/− 버튼을 클릭하여 1씩 조정하거나, 숫자 필드에 직접 값을 입력하고 Enter 키를 누릅니다.
  • 레벨 +/− 버튼을 클릭하거나 레벨(1~80)을 직접 입력합니다.
  • 인벤토리 탭에서 모든 맵 잠금 해제 + 패스트 트래블 버튼을 클릭하면 모든 패스트 트래블 포인트가 해금됩니다.
  • 잠긴 장비 슬롯(무기/방어구/음식/장신구)을 클릭하여 잠금 해제를 시도합니다 — 툴팁을 통해 어떤 아이템이 필요한지 확인할 수 있습니다.

고급 단축키 (더블 클릭 상호작용)

  • 인벤토리 또는 주요 아이템 그리드의 아이템을 더블 클릭하여 확인 창 없이 직접 삭제합니다.
  • 비어 있는 슬롯을 더블 클릭하여 아이템 추가 대화 상자를 엽니다.
  • 아이템이 있는 장비 슬롯을 더블 클릭하여 해당 아이템을 제거할 수 있으며, 비어 있는 장비 슬롯을 더블 클릭하면 해당 슬롯의 아이템 추가 선택기를 엽니다.

숨겨진 메뉴 (우클릭 컨텍스트)

  • 아이템이 들어 있는 인벤토리 슬롯을 우클릭하여 다음 메뉴 이용: 수량 편집, 삭제, 아이템 추가.
  • 빈 슬롯을 우클릭하여 다음 메뉴 이용: 아이템 추가, 슬롯 초기화 (손상된 슬롯에 유용).
  • 장비 슬롯을 우클릭하여 다음 메뉴 이용: 수량 편집 (음식 슬롯 전용), 슬롯 초기화 또는 아이템 추가.
  • 아이템 선택기 대화 상자에서는 검색 결과를 더블 클릭하여 아이템을 즉시 추가할 수도 있습니다.

고급 사용자 팁

아이템 위에 마우스를 올리면 아이템 이름, 수량, 내부 ID 및 전체 게임 설명이 담긴 툴팁이 표시됩니다. 정렬 버튼은 아이템을 카테고리별로 정리해 줍니다. 주요 아이템 탭에는 대량 작업을 위한 "모든 조각상 추가" 및 "모든 주요 아이템 추가" 전용 버튼이 있습니다.
