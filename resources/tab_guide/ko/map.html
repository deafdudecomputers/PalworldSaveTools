기능 개요

거점 마커(집 아이콘), 플레이어 마커(사람 아이콘) 및 제외 구역을 표시하는 대화형 월드 맵입니다. 마커를 클릭하여 거점/플레이어를 확인하고, 마우스 오른쪽 버튼을 클릭하여 관리 작업을 수행하며, 사이드바 트리를 사용하여 길드별로 탐색하세요.

기본 조작 (왼쪽 클릭 및 버튼)

  • 마커를 클릭하여 선택합니다(글로우 효과로 강조 표시).
  • 마우스 휠을 스크롤하여 확대/축소합니다(단계당 1.15x, 범위 1.0x–30.0x).
  • 빈 공간을 클릭하고 드래그하여 시점을 이동합니다.
  • 툴바 버튼(거점, 플레이어, 반경 링, 제외 구역)을 통해 맵 오버레이를 전환합니다.
  • 월드 맵 보기와 트리 맵 보기 간을 전환합니다.
  • 검색창으로 길드 또는 플레이어 이름에 따라 마커를 필터링합니다.
  • 좌측의 거점/플레이어 탭 버튼으로 거점 트리 및 플레이어 트리 패널 간을 전환합니다.
  • 보정을 클릭하여 정확한 좌표 정렬을 위한 보정 모드로 진입합니다.

고급 단축키 (더블 클릭 상호작용)

  • 거점 또는 플레이어 마커를 더블 클릭하면 맵 보기가 해당 마커 위치로 26.0x 확대 및 이동하며 정보 패널이 해당 상세 정보로 업데이트됩니다.
  • 구역 항목(맵에 그린 제외 구역)을 더블 클릭하면 이름 변경 대화상자가 열립니다.
  • 사각형(Rect) 선택 상태의 구역 그리기 모드: 첫 번째 더블 클릭으로 모서리 A를 설정하고, 두 번째 더블 클릭으로 모서리 B를 설정하여 구역을 생성합니다.
  • 3개 이상의 점이 있는 다각형(Polygon) 모드: 더블 클릭하면 다각형 구역이 닫히며 생성됩니다.

숨겨진 메뉴 (마우스 오른쪽 버튼 클릭 컨텍스트)

  • 거점 마커를 마우스 오른쪽 버튼으로 클릭: 거점 삭제, 거점 내보내기, 반경 조정.
  • 플레이어 마커를 마우스 오른쪽 버튼으로 클릭: 플레이어 삭제, 플레이어 이름 변경, 관상용 케이지 잠금 해제, 기술 잠금 해제.
  • 빈 맵 공간을 마우스 오른쪽 버튼으로 클릭: 거점 가져오기, 구역 그리기, 모든 구역 지우기, 구역 내보내기, 구역 가져오기.
  • 거점/플레이어 트리의 항목을 마우스 오른쪽 버튼으로 클릭하여 길드 레벨 작업(길드 이름 변경, 길드 삭제, 길드 거점 내보내기/가져오기, 컨테이너 ID 업데이트)을 포함한 추가 작업을 수행합니다.
  • 맵상의 구역을 마우스 오른쪽 버튼으로 클릭: 구역 삭제(확인창 포함), 구역 이름 변경.

고급 사용자 팁

구역 그리기 모드에서 Escape 키를 누르면 취소하고 즉시 종료됩니다. 알려진 위치를 마우스 왼쪽 버튼으로 클릭하고 실행 취소하려면 마우스 오른쪽 버튼을 클릭하여 보정 모드(보정 버튼)를 통해 맵을 게임 좌표와 정확하게 정렬하세요.
