기능 개요

세이브 파일 내 모든 플레이어의 검색 가능한 테이블입니다. 열에는 플레이어 이름, 마지막 접속, 레벨, 팰 수, UID, 길드 이름, 길드 ID, 길드 레벨이 표시됩니다. 여러 플레이어에 대한 아이템, 팰, 기술 관리를 위해 하단의 일괄 작업 버튼을 사용하세요.

기본 조작 (왼쪽 클릭 및 버튼)

  • 검색창에 입력하여 실시간으로 플레이어를 필터링합니다. 일치하는 모든 열이 표시됩니다.
  • 행을 클릭하여 선택합니다.
  • 대량 아이템 관리를 클릭하여 플레이어 아이템 작업 대화상자를 엽니다(선택한 플레이어 간 아이템 추가/제거).
  • 팰 작업을 하려면 대량 팰 관리를 클릭합니다.
  • 기술 잠금을 해제하려면 대량 기술 관리를 클릭합니다.

고급 단축키 (더블 클릭 상호작용)

  • 플레이어 행을 더블 클릭하면 item_double_clicked 시그널이 발생합니다.
  • 하지만 현재 코드에는 기본 핸들러가 연결되어 있지 않아 더블 클릭 시 눈에 보이는 효과가 없습니다.
  • (향후 사용을 위해 준비된 기능입니다.)

숨겨진 메뉴 (마우스 오른쪽 버튼 클릭 컨텍스트)

  • 플레이어 행을 마우스 오른쪽 버튼으로 클릭: 제외 추가/제거, 플레이어 삭제, 플레이어 이름 변경, 관상용 케이지 잠금 해제, 타임스탬프 재설정, 컨테이너 ID 업데이트, 모든 기술 잠금 해제, 기술 포인트 편집, 플레이어 능력치 편집, 플레이어 레벨 설정.
  • 또한 해당 플레이어의 길드에 대한 길드 레벨 작업도 포함됩니다: 길드 리더 지정, 길드 삭제, 길드 이름 변경, 모든 연구소 연구 잠금 해제, 길드 레벨 설정, 거점을 길드로 가져오기.

고급 사용자 팁

열 헤더를 클릭하여 모든 열을 정렬할 수 있습니다. UID 열(열 인덱스 4)은 제외 및 삭제 작업의 키 참조로 사용됩니다. 방치된 플레이어를 일괄 정리하려면 마지막 접속 날짜를 확인한 후 메뉴 → 기능 → 비활성 플레이어 삭제를 사용하세요.
