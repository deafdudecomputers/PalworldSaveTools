기능 개요

모든 플레이어가 소유한 팰을 심층 편집할 수 있는 인터페이스입니다. 파티(활성 분대) 및 팰 박스(보관함)별로 정리된 팰을 둘러보며 능력치, 개체값, 액티브 스킬, 패시브 특성, 작업 적성, 등급, 소울 강화, 외형 플래그(보스/럭키/각성/DNA) 등을 제어할 수 있습니다. 오른쪽 정보 패널에 편집 가능한 모든 세부 정보가 표시됩니다.

기본 조작 (왼쪽 클릭 및 버튼)

  • 플레이어 선택...을 클릭하여 검색 가능한 팝업에서 플레이어를 선택합니다 (입력하여 필터링, Enter로 선택).
  • 파티 또는 팰 박스 슬롯을 클릭하여 편집할 팰을 선택하면 정보 패널에 편집 가능한 모든 필드가 채워집니다.
  • 정보 패널 헤더의 토글 버튼을 클릭합니다: 성별, 보스 알파, 럭키/샤이니, 각성, 가져오기/DNA, 모든 능력치 최대화.
  • 즐겨찾기 별을 클릭하여 잠금 레벨(0~3)을 전환합니다.
  • 라벨 필드를 클릭하여 입력 대화 상자에서 직접 편집합니다: 이름(별명), 레벨(1~80), 신뢰 등급(0~10).
  • 개체값(IV) 라벨(HP/공격/방어)을 클릭하여 0~100으로 설정합니다.
  • 소울 라벨(HP/공격/방어/작업 속도)을 클릭하여 0~20으로 설정합니다.
  • 액티브 스킬 슬롯을 클릭하여 스킬 선택기를 엽니다.
  • 패시브 스킬 슬롯을 클릭하여 패시브 선택기를 엽니다.
  • 작업 적성 값을 클릭하여 레벨(0~10)을 설정합니다.
  • 팰 박스 페이지를 ← 이전 / 다음 → 버튼이나 그리드 마우스 휠을 사용하여 이동합니다.

고급 단축키 (더블 클릭 상호작용)

  • 팰이 있는 파티 또는 팰 박스 슬롯을 더블 클릭하여 빠르게 삭제합니다 (확인 창 없음 — 컨텍스트 메뉴의 'delete_direct' 동작과 동일).
  • 비어 있는 파티 또는 팰 박스 슬롯을 더블 클릭하여 새 팰 추가 생성 대화 상자를 엽니다.
  • 새 팰 추가 목록에서 팰을 더블 클릭하면 즉시 생성됩니다.
  • FramelessDialog 제목 표시줄을 더블 클릭하여 최대화를 전환합니다.

숨겨진 메뉴 (우클릭 컨텍스트)

  • 팰이 있는 파티 또는 팰 박스 슬롯을 우클릭하여 다음 메뉴 이용: 보스 알파 토글, 럭키/샤이니 토글, 각성 토글, 가져오기/DNA 토글, 잠금 레벨(하위 메뉴: 4개 레벨), 모든 능력치 최대화, 모든 기술 습득, 습득한 스킬 대화 상자, 팰 대량 동기화, 삭제.
  • 빈 슬롯을 우클릭하여 다음 메뉴 이용: 새 팰 추가.
  • 정보 패널의 팰 초상화를 우클릭해도 동일한 확장 컨텍스트 메뉴가 표시됩니다.

고급 사용자 팁

키보드 단축키로 편집 속도를 높일 수 있습니다: Q = 이전 팰 박스 페이지, E = 다음 팰 박스 페이지, F = 정보 패널로 포커스 및 스크롤, C = 스킬 보기 전환. 슬롯 위에 마우스를 올려놓으면 선택하지 않고도 정보 패널에서 해당 팰을 미리 볼 수 있습니다. 컨텍스트 메뉴의 대량 동기화 기능을 사용하면 한 팰의 능력치/스킬/패시브를 여러 팰에 한 번에 복사할 수 있습니다.
