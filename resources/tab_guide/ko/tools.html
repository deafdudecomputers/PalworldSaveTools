기능 개요

세이브 파일 관리를 위한 중앙 허브 — JSON과 SAV, GamePass와 Steam 형식 간 변환, 세이브 간 캐릭터 전송, 손상된 호스트 세이브 복구, 플레이어 슬롯 인젝션 기능을 제공합니다. 각 도구는 아이콘과 설명이 포함된 클릭 가능한 카드로 표시됩니다.

기본 조작 (좌클릭 및 버튼)

  • 작업을 실행하려면 도구 카드를 클릭하세요(세이브 변환, GamePass→Steam 변환, SteamID 변환, 맵 복원, 슬롯 인젝터, 세이브 수정, 캐릭터 전송, 호스트 세이브 복구).
  • 헤더의 세이브 불러오기 버튼을 사용하거나 메뉴 → 파일 → 세이브 불러오기 경로를 이용하세요.
  • 제목 아래의 세이브 경로 레이블을 클릭하면 파일 탐색기에서 현재 세이브 위치가 열립니다.
  • 상태 표시줄의 빠른 탐색 아이콘(플레이어, 길드, 거점, 팰)을 누르면 해당 탭으로 바로 이동합니다.

고급 단축키 (더블 클릭 상호작용)

  • 도구 카드에는 더블 클릭 동작이 없으며, 클릭 한 번으로 실행됩니다.
  • 변환 옵션 대화 상자(SAV↔JSON)에서는 목록 항목 더블 클릭이 지원되지 않으며, 옵션 버튼을 사용해야 합니다.

숨겨진 메뉴 (우클릭 컨텍스트)

  • 도구 카드에는 우클릭 동작이 없으며, 모든 기능은 좌클릭으로만 작동합니다.
  • 하지만 상단 좌측의 메뉴 버튼에는 카드로 제공되지 않는 다양한 정리 기능이 포함되어 있습니다: 빈 길드 삭제, 비활성 거점/플레이어 삭제, 중복 플레이어 삭제, 불법 팰 수정, 유효하지 않은 아이템/구조물/팰 제거, 던전/유전/침략자/보급품 재설정, 모든 구조물 수리, 개인 상자 잠금 해제 등.

고급 사용자 팁

창에 .sav 파일을 끌어다 놓으면 즉시 세이브를 불러옵니다 — 녹색 드롭 존 오버레이로 확인할 수 있습니다. 변환 도구를 사용하기 전에는 항상 백업하세요. 메뉴 → 변경 사항 저장을 통해 정기적으로 변경 사항을 저장하세요.
