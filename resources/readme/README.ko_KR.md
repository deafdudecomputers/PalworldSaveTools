## 개요

<img src="https://readme-typing-svg.demolab.com?lines=%EC%9D%B4%EA%B2%8C+%EC%A0%95%ED%99%95%ED%9E%88+%EB%AD%90%EC%A3%A0%3F;%EB%8B%B9%EC%8B%A0%EC%9D%98+%EC%A0%80%EC%9E%A5%2C+%EB%8B%B9%EC%8B%A0%EC%9D%98+%EB%B0%A9%EC%8B%9D;%EB%AA%A8%EB%93%A0+%EA%B2%83%EC%9D%84+%EC%A7%80%EB%B0%B0%ED%95%98%EB%8A%94+%ED%95%98%EB%82%98%EC%9D%98+%EB%8F%84%EA%B5%AC&center=true&width=490&height=28&font=monospace&size=22&color=7DD3FC&vCenter=true" alt="" />

</div>

Palworld Save Tools(PST)는 Palworld 세이브 파일을 확인하고 편집하는 빠른 올인원 데스크톱 애플리케이션입니다. Python과 PySide6으로 제작되었으며, 별도의 게임 모드 없이 게임의 압축 세이브 형식을 직접 읽고 씁니다.

데디케이티드 서버 관리, 코옵과 데디케이티드 서버 간 이전, 방치된 데이터 정리, 개별 팰 세부 조정까지 PST의 하나의 통합 인터페이스에서 모두 처리할 수 있습니다.

### 하이라이트

- **크로스 플랫폼** — **Windows**, **Linux**, **macOS**용 사전 빌드 바이너리를 제공합니다.
- **빠른 네이티브 파싱** — [`palsav`](../../src/palsav) 엔진을 사용해 세이브 파일을 매우 빠르게 읽습니다.
- **시각적 맵** — 거점/플레이어 마커, 제외 구역, 좌표 보정 기능이 있는 인터랙티브 월드 맵을 제공합니다.
- **세밀한 팰 편집** — 능력치, 개체값, 소울, 스킬, 패시브, 작업 적성, 등급, 외형 플래그를 모두 제어할 수 있습니다.
- **서버 관리 도구** — 관리자를 위한 일괄 삭제, 정리, 변환, 캐릭터 이전 기능을 제공합니다.
- **자동 백업** — 변경 사항을 저장하기 전에 항상 백업을 생성합니다.
- **9개 언어** — 현지화된 UI, 앱 내 가이드, 문서를 제공합니다.

### 플레이어 관리

- 이름, 레벨, 팰 수, UID, 길드, 마지막 접속 시간을 기준으로 모든 플레이어를 확인하고 검색합니다.
- 플레이어의 이름, 레벨, 능력치, 기술 포인트를 편집합니다.
- **능력치 탭** — 게임 내 계산값이 정확히 반영된 캐릭터 능력치(HP, 스태미나, 공격력, 방어력, 작업 속도, 소지 중량)와 토글·스피너 방식의 유물 능력을 제공합니다.
- **모든 능력치 최대화** — 모든 능력치를 즉시 최대치(50포인트)로 설정합니다.
- 여러 플레이어의 아이템 관리, 팰 관리, 기술 잠금 해제를 **일괄 처리**합니다.
- 지정한 미접속 기간을 기준으로 비활성 플레이어를 삭제하고 중복 플레이어를 제거합니다.

### 팰 에디터

어느 플레이어가 소유한 팰이든 세밀하게 편집할 수 있습니다. 팰은 **파티**(활동 스쿼드)와 **팰 박스**(보관함)로 구분됩니다.

- **능력치 및 개체값** — HP, 공격력, 방어력(개체값 0–100), 레벨(1–80), 신뢰 등급(0–10).
- **소울** — HP, 공격, 방어, 제작 속도(0–20).
- **스킬** — 액티브 스킬을 선택하고 모든 기술을 습득하며 여러 팰의 스킬을 일괄 동기화합니다.
- **패시브 특성** — 전체 게임 데이터가 포함된 패시브 선택기를 제공합니다.
- **작업 적성** — 각 작업 적성 레벨(0–10)을 설정합니다.
- **외형 플래그** — 보스/알파, 럭키/샤이니, 프레데터, 각성, 가져오기/DNA 상태를 전환합니다.
- **등급 및 잠금** — 등급과 즐겨찾기 잠금 레벨(0–3)을 설정합니다.
- **치트 모드** — 레벨, 개체값, 소울, 농축 등급 제한을 255까지 확장하고, 중복을 허용한 액티브/패시브 스킬을 제한 없이 사용합니다.
- **내보내기/가져오기** — 팰을 우클릭하여 `.pstpal`(압축) 또는 `.json`으로 내보냅니다. 파티, 팰 박스, DPS, 거점 작업자의 빈 슬롯으로 가져올 수 있으며 세이브 파일과 플레이어가 달라도 사용할 수 있습니다.
- **모든 팰 최대화** — 파티, 모든 팰 박스 페이지, 모든 거점 작업 팰의 능력치(개체값, 소울, 등급, 레벨)를 치트 모드 제한에 맞춰 최대화합니다.
- **비정상 팰 수정** — 플레이어별로 허용 범위를 벗어난 능력치, 스킬, 특성을 감지하고 상한값으로 조정합니다.
- **일괄 복제/삭제** — 종 선택 대화 상자에서 수량과 대상 위치(파티/팰 박스/DPS)를 지정해 일괄 처리합니다.
- 새 팰을 추가하거나 더블클릭으로 빠르게 삭제합니다.

### 길드 관리

위쪽에는 길드 목록, 아래쪽에는 길드원 목록이 표시되는 2단 패널입니다.

- 길드 이름과 리더를 변경하고 길드 레벨을 설정하거나 최대화합니다.
- 모든 연구소 연구를 잠금 해제하고 모든 길드를 다시 구성합니다.
- 플레이어를 길드 간 이동하고 비어 있거나 비활성인 길드를 삭제합니다.

### 거점 도구

- 길드 소속 정보와 함께 모든 거점을 확인합니다.
- 거점 설계도를 `.json`으로 **내보내고**, 단일 또는 여러 파일을 어느 길드로든 **가져옵니다**.
- 위치 오프셋을 적용해 다른 길드로 거점을 **복제**합니다.
- **좌표 변경** — 맵에서 거점 마커를 우클릭하고 "좌표 변경"을 선택한 뒤 원하는 위치를 클릭해 거점을 이동합니다.
- **거점 미세 이동** — 정확한 X/Y/Z 오프셋으로 거점을 이동해 지면 관통이나 공중 부양 문제를 해결합니다.
- **거점 반경을 조정**합니다(50%–1000%).
- 비활성 거점과 거점이 아닌 맵 객체를 삭제합니다.

### 맵 뷰어

월드 전체를 인터랙티브하게 시각화합니다.

- 상세 패널이 있는 거점 마커(집 아이콘)와 플레이어 마커(사람 아이콘)를 표시합니다.
- 거점, 플레이어, 반경 원, 제외 구역 오버레이를 켜거나 끕니다.
- **구역 그리기** — 맵에 직사각형 또는 다각형 제외 구역을 직접 그립니다.
- **보정 모드** — 맵을 게임 좌표에 정확히 맞춥니다.
- 월드 맵과 트리 맵을 전환하고 길드 또는 플레이어 이름으로 필터링합니다.
- 1.0x–30.0x 확대/축소, 화면 이동, 더블클릭으로 마커 이동을 지원합니다.
- 마커나 빈 공간을 우클릭해 관리 작업을 실행합니다.

### 인벤토리 관리

**플레이어 인벤토리** — 다음 세 가지 하위 탭을 제공합니다.
- *인벤토리* — 주 가방의 모든 아이템과 장비를 확인하고 수량 편집, 추가, 제거를 수행합니다.
- *중요 아이템* — 퀘스트 아이템, 조각상, 기술을 관리하고 모든 조각상/중요 아이템을 일괄 추가합니다.
- *능력치* — 레벨, HP, 스태미나, 공격력, 방어력, 작업 속도, 소지 중량을 편집합니다.
- 무기, 액세서리, 음식, 방어구, 방패, 글라이더, 모듈 슬롯용 장비 패널을 제공합니다.
- 클릭 한 번으로 맵 전체와 모든 패스트 트래블 지점을 잠금 해제합니다.

**거점 인벤토리** — 모든 거점의 아이템과 작업 팰을 살펴보고 관리합니다.
- 컨테이너의 아이템을 확인·편집하고, 컨테이너를 비우거나 슬롯을 변경합니다.
- 모든 길드에서 아이템을 찾거나 제거하는 길드 간 아이템 작업을 지원합니다.
- 여러 길드에 걸쳐 구조물을 삭제합니다.
- **거점 팰** 하위 탭 — 팰 에디터의 전체 컨텍스트 메뉴를 사용해 각 거점에 배치된 작업 팰을 관리합니다.

### 제외

플레이어, 길드, 거점을 정리 작업에서 보호하는 목록입니다.

- 나란히 배치된 세 패널에 제외된 플레이어 UID, 길드 ID, 거점 ID를 표시합니다.
- 플레이어, 길드, 거점 탭의 우클릭 컨텍스트 메뉴에서 항목을 추가합니다.
- 제외 목록을 저장하고 불러와 계속 사용합니다.
- 일괄 정리를 실행하기 **전에** 목록을 구성하세요.

**도구** 탭에서 각 카드를 클릭해 실행할 수 있습니다.

### 정리 및 유틸리티 기능

**메뉴 → 기능**에서 다음 서버 관리 작업을 실행할 수 있습니다.

- **PalDefender** — `killnearestbase` 명령을 생성합니다.

### 호스트 변경(코옵 교환)

<details>
<summary>펼쳐 보기</summary>

두 플레이어가 호스트 역할을 바꾸려는 상황입니다. 현재 호스트인 플레이어 A의 캐릭터는 `0001.sav`에 있고, 클라이언트로 참가한 플레이어 B의 캐릭터는 `1234.sav`에 있습니다. 플레이어 B가 호스트가 되려면 항상 `0001.sav`인 호스트 슬롯으로 옮겨야 합니다.

**핵심 개념 — 호스트 세이브 복구는 항상 두 플레이어를 교환합니다.** 두 사람이 자리를 바꾸듯 세이브 파일을 맞바꾸며, 한 파일을 다른 파일 위에 복사하지 않습니다. 교환 후에도 두 플레이어는 모두 존재하고 파일 위치만 달라집니다.

첫 번째 교환으로 플레이어 B를 호스트 슬롯에 옮기면 플레이어 A의 데이터가 B의 기존 파일에 남습니다. 플레이어 A의 원래 캐릭터를 다시 연결하려면 두 번째 교환이 필요합니다.

---

**시작 상태:**
```
0001.sav  = Player A (current host)
1234.sav  = Player B (current client)
```

---

**1단계 — A와 B를 교환합니다.**
- PST → **도구** → **호스트 세이브 복구**를 여세요.
- 코옵의 `Level.sav`를 선택하세요.
- **원본**: 플레이어 A(`0001.sav`). **대상**: 플레이어 B(`1234.sav`).
- 버튼을 클릭하세요. 두 파일이 교환됩니다.

**1단계 이후:**
```
0001.sav  = Player B  ← now the host with B's character
1234.sav  = Player A  ← A's data is here, but this UID no longer exists in the game
```

---

**2단계 — 플레이어 B가 호스트하고 플레이어 A가 참가합니다.**
- 플레이어 B가 월드를 호스트하고 플레이어 A가 참가하세요.
- A는 더 이상 호스트가 아니므로 Palworld가 A의 임시 캐릭터에 새 UID(예: `9999.sav`)를 할당합니다.
- 플레이어 A가 임시 캐릭터로 **레벨 2**에 도달한 뒤 모두 게임을 종료하세요.

**2단계 이후:**
```
0001.sav  = Player B (host, correct)
1234.sav  = Player A's original data (not linked to any active UID)
9999.sav  = Player A's temporary character (fresh, Level 2+)
```

---

**3단계 — A의 원본 데이터를 A의 새 UID로 교환합니다.**
- 같은 `Level.sav`으로 **호스트 세이브 복구**를 다시 여세요.
- **원본**: `1234.sav`(플레이어 A의 원본 데이터). **대상**: `9999.sav`(플레이어 A의 임시 캐릭터).
- 버튼을 클릭해 다시 교환하세요.

**3단계 이후:**
```
0001.sav  = Player B (host, correct)
1234.sav  = Player A's temp character (unused, can delete)
9999.sav  = Player A's original character  ← restored!
```

---

**완료되었습니다.** 플레이어 B는 원래 캐릭터로 호스트하고 플레이어 A도 원래 캐릭터로 참가합니다. 남은 `1234.sav`은 무시하거나 삭제해도 됩니다.

> **왜 두 번 교환해야 하나요?** 호스트 세이브 복구는 복사가 아니라 두 파일을 **교환**합니다. 첫 번째 교환에서 B는 호스트 슬롯으로 이동하지만 A의 데이터는 게임에서 더 이상 사용하지 않는 B의 기존 UID에 남습니다. 두 번째 교환으로 A의 데이터를 새 클라이언트 UID에 연결해야 모든 진행도가 보존됩니다.

</details>

### 캐릭터 이전(교차 세이브)

<details>
<summary>펼쳐 보기</summary>

플레이어의 모든 팰, 인벤토리, 기술, 진행도를 한 월드에서 다른 월드로 복사합니다. 코옵 월드와 데디케이티드 서버 사이 또는 서로 다른 서버 사이에서 캐릭터를 옮길 때 유용합니다.

**작동 방식:** 두 파일을 **교환**하는 호스트 세이브 복구와 달리, 캐릭터 이전은 한 `Level.sav`에서 다른 `Level.sav`으로 플레이어를 **복사**합니다. 원본 세이브 파일은 변경되지 않습니다.

1. PST → **도구** → **캐릭터 이전**을 여세요.
2. **원본 세이브 불러오기** — 원본 버튼을 클릭하고 복사할 캐릭터가 있는 `Level.sav`(예: 이전 서버)을 선택하세요.
3. **대상 세이브 불러오기** — 대상 버튼을 클릭하고 캐릭터를 복사할 `Level.sav`(예: 새 서버)을 선택하세요.
4. 왼쪽 원본 플레이어 목록에서 이전할 플레이어를 선택하세요.
5. 오른쪽 대상 플레이어 목록에서 **배치할 위치를 선택**하세요. 기존 플레이어를 덮어쓰거나 새 슬롯을 비워 둘 수 있습니다.
6. **이전**을 클릭하세요. 캐릭터, 팰, 인벤토리, 길드 소속이 대상 세이브 파일로 복사됩니다.
7. 변경 사항을 저장하세요. 백업은 자동으로 생성됩니다.

"모두 이전" 버튼으로 **모든 플레이어**를 한 번에 이전할 수도 있습니다.

</details>

### 거점 내보내기/가져오기/복제

<details>
<summary>펼쳐 보기</summary>

**거점 내보내기:**
1. **거점** 탭으로 이동하세요(또는 맵 뷰어를 사용하세요).
2. 거점을 우클릭 → **거점 내보내기**를 선택하세요.
3. `.json` 청사진 파일로 저장합니다.

**거점 가져오기:**
1. 거점 탭, 맵 뷰어 또는 길드 탭에서 대상 길드를 우클릭하세요.
2. **거점 가져오기**(단일 파일) 또는 **거점 가져오기(여러 파일)**를 선택하세요.
3. 내보낸 `.json` 파일을 선택합니다.

**거점 복제:**
1. 거점을 우클릭 → **거점 복제**를 선택하세요.
2. 대상 길드를 선택하세요.
3. 위치 오프셋을 적용해 거점이 복제됩니다.

**거점 반경 조정:**
1. 거점을 우클릭 → **반경 조정**을 선택하세요.
2. 새 반경(50%~1000%)을 입력합니다.
3. 구조물을 다시 배정하려면 저장한 뒤 게임에서 세이브 파일을 다시 불러오세요.

</details>

## 문제 해결

<img src="https://readme-typing-svg.demolab.com?lines=%EC%9D%BC%EC%9D%B4+%EC%98%86%EC%9C%BC%EB%A1%9C+%ED%9D%98%EB%9F%AC%EA%B0%88+%EB%95%8C;%EB%8B%B9%ED%99%A9%ED%95%98%EC%A7%80+%EB%A7%88%EC%84%B8%EC%9A%94;%EC%9A%B0%EB%A6%AC%EB%8A%94+%EA%B7%B8%EA%B2%83%EC%9D%84+%EB%AA%A8%EB%91%90+%EB%B3%B4%EC%95%98%EB%8B%A4&center=true&width=390&height=28&font=monospace&size=22&color=7DD3FC&vCenter=true" alt="" />

</div>

### "VCRUNTIME140.dll을 찾을 수 없습니다"(Windows)

[Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)(2015–2022)을 설치하세요.

### 세이브 파일 파싱 중 `struct.error` 발생

세이브 파일 형식이 오래되었습니다. 게임(솔로, 코옵 또는 데디케이티드 서버)에서 세이브 파일을 한 번 불러와 구조가 자동으로 업데이트되게 한 뒤 다시 시도하세요. 최신 게임 패치 이후에 세이브 파일이 업데이트되었는지도 확인하세요.

### Game Pass 변환기가 작동하지 않음

1. Palworld의 Game Pass 버전을 완전히 종료하세요.
2. 파일 핸들이 해제될 때까지 몇 분 정도 기다립니다.
3. Game Pass → Steam 변환기를 실행하세요.
4. Game Pass에서 Palworld를 실행해 결과를 확인하세요.

### Linux/macOS 바이너리가 실행되지 않음

- **Linux:** `chmod +x PalworldSaveTools-*-linux.AppImage`를 실행해 실행 권한을 부여하세요.
- **macOS:** Gatekeeper에 의해 차단된 경우 마우스 오른쪽 버튼을 클릭하고 → **열기**를 클릭하거나 `xattr -d com.apple.quarantine /path/to/app`을 실행하세요.

## 소스에서 빌드

<img src="https://readme-typing-svg.demolab.com?lines=%EC%A7%81%EC%A0%91+%EC%BB%B4%ED%8C%8C%EC%9D%BC%ED%95%B4%EB%B3%B4%EC%84%B8%EC%9A%94;%EB%82%98%EB%A7%8C%EC%9D%98+%EA%B2%83%EC%9D%84+%EB%A7%8C%EB%93%A4%EC%96%B4%EB%B3%B4%EC%84%B8%EC%9A%94;%EC%86%8C%EC%8A%A4%EC%97%90%EC%84%9C+%EB%B0%94%EC%9D%B4%EB%84%88%EB%A6%AC%EB%A1%9C&center=true&width=340&height=28&font=monospace&size=22&color=7DD3FC&vCenter=true" alt="" />

</div>

PST는 두 가지 빌드 방식을 지원합니다. CI/CD 파이프라인은 크로스 플랫폼 릴리스 바이너리에 Nuitka를 사용하고, 로컬 Windows 설치 프로그램에는 cx_Freeze를 사용합니다.

### Nuitka(크로스 플랫폼 — CI/릴리스에서 사용)

Python 3.11+와 `uv`가 필요합니다. Nuitka는 자동으로 설치됩니다.

```bash
# One-file build (Windows / Linux)
uv run python build/nuitka/build_nuitka.py --onefile

# One-directory build (macOS .app)
uv run python build/nuitka/build_nuitka.py --onedir
```

결과물은 `dist/`에 생성됩니다.
- Windows → `dist/PalworldSaveTools-*.exe`
- Linux → `dist/PalworldSaveTools-*-linux`
- macOS → `dist/PalworldSaveTools.app` → `.dmg`으로 패키징

### cx_Freeze(Windows 설치 관리자)

로컬 Windows `.zip` 패키지의 경우:

```
scripts\build_cx.cmd
```

그러면 프로젝트 루트에 `PST_standalone_v{version}.zip`이 생성됩니다.

### 인터랙티브 빌더

빌드 모드를 선택하는 인터랙티브 메뉴입니다.

```bash
uv run python build/build_interactively.py
```
